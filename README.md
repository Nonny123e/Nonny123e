# Chinonso E. — Portfolio

A static portfolio site with a flagship case study. No build step or dependencies.

## Files
| File | Purpose |
| --- | --- |
| `index.html` | Home page: hero, selected work, services, process, about, contact |
| `case-study.html` | Fabrics & Curtains concept case study |
| `styles.css` | Shared design tokens, navigation, buttons, footer and home-page styles |
| `case-study.css` | Styles used only by the case study |
| `script.js` | Mobile menu (with Escape to close) and footer year |
| `favicon.svg` | Site icon |

Open `index.html` in a browser to preview. Keep all files in the same folder.

## Before publishing
- Replace `hello@example.com` (3 places in `index.html`, 1 in `case-study.html`).
- Add real project imagery to replace the CSS fabric illustrations.
- Add a live project or client work when available, with verified outcomes.
- Decide whether the headline positioning includes Webflow, and update the page title, description and hero to match.
- Add an Open Graph image, domain/canonical URL, analytics and any legal pages.
- Test on real phones and with keyboard-only navigation.
